Maxfiylik siyosati

Kuchga kirgan sana: 2026-yil 24-noyabr · AI rozilik versiyasi: 2026-11-24-v1

Voilà! fransuz tilini A1–C2 darajalarida o‘rganish xizmatidir. Ushbu sahifa ilovada saqlanadigan ma’lumotlar va AI roziligi berilganda yuz berishi mumkin bo‘lgan ishlov haqida tushuntiradi.

1. AI xizmatining hozirgi holati

Hozir nomlangan Google AI server yo‘li o‘chiq: quyida sanalgan yetti AI endpoint ishlamaydi va rozilik oynasidagi checkbox ularni yoqmaydi. Ilovaning runtime javobida server AI va STT o‘chiq; server TTS inson tomonidan tekshirilmagan va runtime’da faqat matn rejimida (tts: 'text') turadi, ya’ni server ovoz yubormaydi; Live ham o‘chiq. Bu server TTS holatidan alohida ravishda, matnli tutor fransuzcha qismlarni brauzer/qurilma SpeechSynthesis orqali sukut bo‘yicha ovozlashtirishi mumkin (batafsil ma’lumot 3-bo‘limda). Google Cloud loyihasi, model, region va sarf cheklovlari alohida sozlanib, tekshirilmagan. Bu holat o‘zgartirilishidan oldin provider, region va ma’lumotlar haqidagi bildirish yangilanadi.

2. Hisob va o‘quv ma’lumotlari

  • Hisob: email, ism, profil rasmi va kirish usuli identifikatori. Parol faqat scrypt xesh ko‘rinishida saqlanadi.
  • O‘quv progressi: darslar, ballar, seriya, so‘zlar, yutuqlar va siz tanlagan Vivi xotira xulosasi qurilmada saqlanadi; hisob ochilgan bo‘lsa progress sinxronizatsiya qilish uchun serverga yuborilishi mumkin.
  • IP manzil: suiiste’mol va so‘rovlar limitini boshqarish uchun ishlatilishi mumkin.
  • To‘lovlar va reklama: Payme yoki Click buyurtma holatini qayta ishlaydi; karta raqami Voilà! serverida saqlanmaydi. Reklama bo‘lsa, Google AdMob/AdSense o‘z siyosatiga muvofiq ishlaydi.

Ma’lumotlaringiz sotilmaydi.

3. AI roziligi va qaysi ma’lumot yuborilishi mumkin

Agar AI yo‘llari keyinchalik alohida tekshirilib yoqilsa, har bir vazifa uchun rozilik alohida olinadi. Rozilik hisobingizga bog‘langan holda serverda versiyasi, tanlangan scope, provayder hamda berilgan/bekor qilingan vaqti bilan saqlanadi. Ro‘yxatdagi scope’lar sukut bo‘yicha tanlanmaydi.

  • Matnli tutor (`text_tutor`): yozgan xabaringiz va kerakli CEFR/mashq konteksti Google Cloud Agent Platform (Gemini) ga yuborilishi mumkin.
  • Javob bo‘yicha fikr (`text_feedback`): siz tasdiqlagan javob va tegishli mashq konteksti shu Google xizmatiga yuborilishi mumkin.
  • Jonli sessiya (`live_session`): sessiya ma’lumoti yuborilishi mumkin. Live hozir o‘chiq; hozirda sessiya yoki token berilmaydi.
  • Tarjima (`translation`): tarjima uchun zarur bo‘lgan matngina yuborilishi mumkin.
  • Xotira (`memory`): faqat siz ko‘rib, saqlashga tasdiqlagan kontekst Google Cloud Agent Platform (Gemini) ga yuborilishi mumkin. Boshqa hisobning xotirasi qo‘shilmaydi.
  • Mikrofon STT (`microphone_stt`): yozib olingan asl audio matnga aylantirish uchun Google Cloud Speech-to-Text ga yuborilishi mumkin. Qaytgan transkript alohida ma’lumot turidir.
  • Server orqali matnni ovozlashtirish (`text_tts`): agar server-side TTS kelajakda yoqilsa, Vivi javobining matni Google Cloud Agent Platform (Gemini TTS) ga yuborilib, hosil bo‘lgan audio qurilmangizga qaytarilishi mumkin. Bu hozir o‘chiq va brauzer/qurilma SpeechSynthesis ishlatadigan matnli tutor ovozidan alohida.

Matn, fikr-mulohaza, tarjima va tasdiqlangan xotira vazifalarida Google Cloud Agent Platform; mikrofon STT vazifasida Google Cloud Speech-to-Text nomi ko‘rsatiladi. Matnli tutor javobidagi fransuzcha qismlarni avtomatik o‘qish sozlamasi yangi profil uchun sukut bo‘yicha yoqilgan; brauzer/qurilma SpeechSynthesis mavjud bo‘lsa, u javob kelganda shu qismlarni ovozlashtiradi. Foydalanuvchi bu sozlamani o‘chirishi yoki javobdagi alohida tinglash tugmasini bosib qo‘lda eshitishi mumkin. Matn tanlangan brauzer/qurilma SpeechSynthesis dvigateliga berilib, shu dvigatelda ovozga aylantiriladi; uning ishlovi va maxfiylik qoidalari tanlangan ovoz/dvigatelga bog‘liq (ayrim ovozlar tarmoq xizmatidan foydalanishi mumkin). Bu matnli tutorning alohida funksiyasi bo‘lib, server TTS uchun fallback emas. Server TTS o‘chiq, sozlanmagan yoki xatoga uchraganida, server oqimida brauzer SpeechSynthesis’ga yashirin fallback qilinmaydi; OpenAI-compatible URL, Gemini Developer API, Groq, Azure, ElevenLabs yoki brauzer SpeechRecognition’ga ham yashirin fallback yo‘q.

Bepul rejim (Google Gemini API / AI Studio). Server egasi shu rejimni tanlagan bo‘lsa, yuqoridagi barcha AI vazifalari (matnli tutor, fikr-mulohaza, tarjima, xotira, mikrofon audiosini matnga aylantirish va Vivi javobini ovozlashtirish) Google Cloud xizmatlari o‘rniga Google Gemini API ga yuboriladi. Rozilik oynasida bunda provayder sifatida «Google Gemini API (AI Studio, bepul tarif)» ko‘rsatiladi va alohida siyosat versiyasi so‘raladi — Google Cloud uchun berilgan rozilik bu rejimga o‘tmaydi. Gemini API’ning bepul tarifida Google yuborilgan matn va audiodan o‘z mahsulotlarini yaxshilash uchun foydalanishi va ularni odamlar ko‘rib chiqishi mumkin (Gemini API qo‘shimcha shartlariga qarang). Shuning uchun Vivi’ga parol, karta raqami, manzil kabi maxfiy ma’lumot yubormang. Bu rejim boshqa rejimga yashirin fallback emas: qaysi rejim ishlatilishini faqat server sozlamasi belgilaydi.

4. Region, saqlash va o‘chirish

Hozir biror Google Cloud region tasdiqlanmagan yoki faol emas. AI yo‘li kelajakda yoqilsa, ishlatiladigan va tasdiqlangan region shu yerda va rozilikdan oldin ko‘rsatiladi; transchegaraviy ishlov joylashuvga bog‘liq bo‘lishi mumkin.

Yangi AI yo‘li hozir o‘chiq. U yoqilganda, Voilà! serveri prompt, memory summary, transkript, asl audio yoki hosil qilingan audioni ilova ma’lumotlar bazasi yoki loglarida saqlamasligi kerak. Bu faqat Voilà! serveridagi saqlashga taalluqli; Google xizmatlarining o‘z saqlash muddati va ishlov shartlariga kafolat bermaydi. Provider ma’lumotlarni qancha muddat saqlashi yoki boshqa maqsadda ishlatishi shartlar va konfiguratsiyaga bog‘liq bo‘lishi mumkin.

Profil → AI roziliklarini boshqarish bo‘limida yangi ishlovni to‘xtatish uchun barcha AI roziligini bekor qiling. Bekor qilish yangi so‘rovlarni to‘sadi, ammo avval yuborilgan ma’lumotni qaytarib olmaydi yoki provider’dagi nusxani o‘chirmaydi. Saqlangan Vivi xotirasini o‘chirish qurilmadagi va server bilan sinxronlangan progressdagi xotira xulosasini o‘chiradi; u suhbat transkriptini, asl audioni yoki provider’da saqlanishi mumkin bo‘lgan ma’lumotni o‘chirmaydi. Hisobni o‘chirish serverdagi hisobni o‘chiradi, ammo provider’ga avval yuborilgan nusxalarni o‘chirmaydi.

5. Boshqa xizmatlar

Kirish provayderlari (masalan, Google), to‘lov xizmatlari va reklama provayderlari o‘z maxfiylik qoidalariga ega. AI roziligi ushbu xizmatlarga tegishli ruxsatlarni avtomatik bermaydi. Google reklama haqida: Google reklama siyosati.
